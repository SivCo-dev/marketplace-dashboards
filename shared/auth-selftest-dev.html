Самопроверка авторизации — logout / «Назад» / смена пользователя

Этот инструмент работает только в вашем браузере. Он не отправляет и не показывает access_token / refresh_token где-либо вне этой страницы и не пишет их в консоль. Прод не затрагивается — все запросы идут на auth-dev эндпоинты.

Проверка сессии…
  1. Шаг 1. Войдите тестовым пользователем (viewer) в окне ниже. После входа оно само откроет «Ежедневный отчёт» и загрузит данные.
  2. Шаг 2. Проверка выхода (logout): приватные данные пропадают из интерфейса, и клиентские хранилища (localStorage/sessionStorage) очищаются.
  3. Шаг 3. Проверка, что защищённые API без токена отвечают 401 (после выхода).
  4. Шаг 4. Проверка кнопки «Назад»: после выхода она не должна возвращать доступ к ранее загруженным данным.
  5. Шаг 5. Войдите в окне ниже другим пользователем (другая роль/tenant), затем нажмите кнопку. Проверяется, что данные и права предыдущего пользователя не сохранились.
